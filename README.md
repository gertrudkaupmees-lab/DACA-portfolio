# DACA-portfolio
Data Analytics Career Accelerator (DACA) portfolio and UrbanStyle analytics projects
## Minust ja Programmist 
Tere! Alustan 11-nädalast intensiivset **Data Analyst Career Accelerator (DACA)** programmi. Programmi jooksul töötan simuleeritud Eesti moeettevõtte **UrbanStyle.ltd** andmetega, et aidata juhtkonnal lahendada andmekaos ja valmistuda investorite kohtumiseks.
## Kasutatavad Tööriistad 
- **Andmebaas:** PostgreSQL / Supabase
- **Päringud &amp; Analüüs:** SQL, Python (pandas)
- **Visualiseerimine:** Power BI / Plotly &amp; Streamlit
- **Versioonihaldus &amp; Editor:** GitHub, VS Code
- **AI-õppekaaslane:** NotebookLM (RAG)
